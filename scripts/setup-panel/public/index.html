部署到我的机器

    密码只用于当场登录，不会写入配置文件。

    检查本机环境

    需要 Node.js 22+、olares-cli、Docker 和 olares-image。跳过 Hub 时还要能 SSH 到节点。

      确认项目名称

      将写入 chart、镜像名和界面品牌名。小写字母开头，至少 4 位，不要用 test、app、web。

      Docker Hub 地址

      要走 Hub 必须填仓库、用户名和密码，测通后才能下一步。也可以跳过，改用 docker save。

      Olares 机器

      填写 Desktop 入口。已登录同一身份时可只填地址。

      节点 SSH

      节点地址由 olares-cli 自动探测。用户名默认 olares；SSH 密码默认也是 olares，改过则到 Vault 取。

      配置已保存

      后续部署只读 .dsh/config.json，不再询问这些项。
